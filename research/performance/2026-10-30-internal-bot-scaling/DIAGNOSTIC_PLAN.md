# Exploratory observation attribution after primary counting

This supplements, and does not replace, the frozen primary plan. Source
inspection found three possible population-dependent observation costs:
rebuilding the food/body indexes for each staggered batch; restoring food order
by walking bitset words; and scanning every snake/prey for each observer.
The 1,000-bot anchor establishes a substantial aggregate observation budget but
does not identify these loops' individual shares. No loop saving is claimed.

After the complete primary series ends, preserve the counted binary, logs and
pins unchanged. Build a separate diagnostic copy of the same harness/runtime
with default portable release codegen and full debug information. No `src/`
edit or production optimization. Record its source/build/binary identity.

Use the frozen 1,000- and 10,000-bot checkpoints, 512 ticks, serial decision
mode. First run without perf, then sample user CPU at 499 Hz with DWARF stacks.
Record both summaries, output-state identity and elapsed/CPU overhead ratios.
Sampled timing is never substituted for a primary observation. If 10,000's
warmup is censored, label that diagnostic's ecology explicitly unqualified.

Before diagnostic execution, add one matched `StepProfile` continuation after
the plain and sampled continuations. Require the same final state, retain its
overhead ratio and CPU phase bounds, and keep its operation counts. The plain
diagnostic's observation, decision and world costs remain a single diagnostic
window, explicitly separate from five-window primary rows. This also provides
a bounded cost profile if 10k never qualifies; it does not relabel that ecology.

The read-only checkpoint census also computes the dense pickup grid's rectangle,
cover-area and food-relative limits using public `physics::pickup_circle` and
the frozen source's 128-unit cells. This is snapshot geometry, not an observed
branch trace: each real step builds circles after movement and deaths. Combine
it with sampled stacks and `StepProfile` work counts before diagnosing a fallback.

Retain only tick-operation stacks for phase attribution; identify loading and
priming separately. Retain unresolvable/unwound samples. Use source lines and
inlined functions to separate index construction, food-order restoration,
snake/prey candidate scans, observation copying and A4 where resolution permits.
Report coarse buckets or unattributed work where it does not. In particular,
do not turn an inclusive observation budget into a removable-loop percentage.
This is diagnostic ranking, not exact-speedup evidence or algorithm adoption.
