# Attempts

The plan was frozen before creating resources. The task uses one Spot pair and
one evolving world. Raw receipts, inventories, source copies and logs are
private; no cloud identifier or endpoint is retained in this study.

- Read-only preflight attempted all 34 commercial regions. Seventeen were
  queryable and empty; seventeen were unavailable to the existing session.
  A fresh Frankfurt inventory immediately before launch was also empty.
- The current combined Spot rate at launch was $0.2128/hour. Both boot-installed
  120-minute shutdown timers and terminate-on-shutdown attributes were verified
  before building. The portable Rust 1.99.0 build completed on the generator,
  and its copied host binary passed the server-side SHA-256 check.
- Warmup began with 350 received-frame A4 socket bots, zero in-process bots and
  the planned resident/rotating cohorts. The restricted public TCP probe passed;
  the private endpoint file was written during warmup.
- Before collection the synthetic arithmetic/gate controls passed. They use
  authored data only and support the reducer contract, not capacity.
- An intermediate documentation check caught the newly drafted report missing
  from the research index. Adding its index row resolves that check; no paid
  attempt or measurement is discarded for it.
- During warmup, added a generator command-inventory observer on control core 7,
  before any counted window. It records the generator's full process commands
  within one polling interval of window transitions. The existing host observer
  already records exact boundary inventories. No workload or gate changed.

- The first world passed the mature screen at ticks 192,000/192,500/193,000:
  mean lengths 55.111/55.194/55.909, p90 185/186/186, p99 237/236/236, and
  351 living including the human player. The 350–750 ladder and descending 700
  confirmation pass all original gates and offline CPU-clock reconciliation.
- The first world stopped at its predeclared 750-slot ceiling, with median
  world CPU 6.406 ms, before the requested CPU boundary. Its selected results
  are retained in `ladder-350-results.json`, including human-affected windows.
  The private endpoint file was removed and teardown began normally.
- The [plan amendment](PLAN.md#amendment-after-the-initial-slot-ceiling) adds one
  fresh 650-start mature world with larger slot allocation after verified first
  cleanup. This is a capacity extension, not a repeat selected for speed; no
  original result or gate is discarded. The whole-test time/cost caps remain.

- First cleanup removed instances, volumes, groups and keys but its scan found
  two active Spot request records. The original controller's key-name matcher
  did not find these direct-launch requests. The correcting launch guard failed,
  but a semicolon-separated PowerShell command still launched the replacement.
  This was a control-flow error. The old requests were then matched using task
  instance/request identity and canceled. There was no overlap of running pairs.
- The maintaining agent explicitly stopped the proposed extension. Its controller
  was killed and both replacement instances were immediately terminated. The
  replacement had no warmup progress, ready endpoint or measured window; its
  68/71 instance-seconds are retained in `cost.json`. Nothing else was launched.
- Cleanup queries briefly failed after credentials expired. An isolated refresh
  of the existing CLI login session allowed cleanup to complete. The isolated
  task cache was removed afterward; the maintaining agent separately reported
  that the human operator reran `aws login`.
- Final agent verification at 02:11 UTC attempted all 34 commercial regions:
  17 queryable/enabled regions have zero nonterminated instances, open/active
  Spot requests, volumes and Elastic IPs; 17 unavailable regions remain labeled.
  All four task instances are terminated, all four requests closed/canceled,
  both runs' groups/keys removed, task volumes gone and the endpoint file absent.
- The maintaining agent independently reported the same zero inventories across
  all 17 enabled regions at approximately 02:15 UTC, plus both runs' removed
  groups/keys and all four closed/canceled requests. Unrelated pre-existing
  resources were left untouched. `cleanup.json` records both verifications.
- Only the first ladder supplies capacity results. All ten windows, younger
  upper-window censuses, human occupancy and the slot-ceiling stop are retained.
  No extrapolated 6.8-ms boundary or fully mature upper-count capacity is claimed.
